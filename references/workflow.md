## 1. 第 1 步 分析市场（01 分析市场）

### 输入与数据准备

- 数据来源：A 股用 `a-stock-data` skill；其他市场以用户提供的数据/图表为准。
- 数据要求：至少提供与声明级别匹配的历史 K 线（最高、最低、收盘、开盘）；截图先提取**极端价位（含影线）**，无法确认影线细节时说明"基于可见图表提取，可能缺少盘中极端点"，不得用收盘价替代（references/rules.md R20）。
- 数据读取输出四要素：数据时间范围；区间最高/最低极端价位（含时间点）；当前价格位置；复权方式 + 数据源 + 截至时间（强制披露，见 references/data.md 第 2 节）。

### 数据自检（01 分析市场 1.5）

进入数浪前对数据基准逐条勾选并输出《数据自检表》（检查项 | 判定结果（通过/不适用/不通过）| 说明）：

- OHLC 合理性：high ≥ low ≥ 0；open/close 落在 [low, high] 内；volume ≥ 0；
- 日期升序、无重复；跳空缺口（停牌/节假日）必须说明；
- 最新一根 K 线盘中/收盘须注明；
- 极端价位取 high/low（references/rules.md R20），不用收盘/开盘；
- 数据范围至少覆盖一个完整 5+3 循环，不足披露；
- 复权口径已标注（none/qfq/hfq）且全程一致；
- 数据源与截至时间已记录。

任一"不通过"退回重新取数或降级标注，禁止带病数浪；《数据自检表》并入分析报告【1. 分析前提】或附录归档。

### 趋势方向判定

- 趋势必须绑定级别（references/terminology.md 1.7.7）。方法 A：从更大级别图表观察（推动浪阶段同向 / 调整浪阶段反向）；方法 B：找最近完整 5+3 循环定位当前段；方法 C：通道与均线辅助（只作定位与概率参考，不能替代结构判定，references/guidelines.md G3）。
- 方向输出三选一：上升趋势 / 下降趋势 / **方向不明（必须说明原因）**。

### 级别选择与输出卡

- 强制要求：任何分析输出必须声明分析级别（references/rules.md R22）；级别变更须说明理由（references/rules.md R4）。
- 选择原则：结构可识别（杂乱无章则放大/缩小一级）；级别是相对的；声明后嵌套必须自洽。
- 输出格式统一：「级别中文名（英文名）+ 标注符号 + 当前所处浪段」，如"日线级别，中浪 Intermediate（(1)(2)(3)(4)(5)），当前运行第 (3) 浪内部"。

**分析市场输出卡**（向 02 移交）：

```text
【分析市场输出卡】
- 分析级别：中浪 Intermediate（(1)(2)(3)(4)(5)），当前处于第 (3) 浪内部
- 趋势方向：上升趋势（依据：周线处于推动浪阶段；日线高点/低点不断抬高）
- 数据基准：2026-01-01 至 2026-08-07；区间最高 3,450（2026-06-15）、最低 2,800（2026-02-03）；当前价格 3,320；复权方式 qfq（前复权，hfq 不可得自动降级）、数据源 腾讯 fqkline、截至时间 2026-08-07 15:00
- 当前所处浪段：第 (3) 浪内部（尚未完成）
- 方向不明说明（如适用）：结构不完整，暂无法判定
```

### 主要摆动与交接

- 摆动点一律用极端价位标记（references/rules.md R20）；范围至少覆盖一个完整 5+3 循环；"显著"程度由分析级别决定。
- 摆动序列格式：序号 | 类型（高/低）| 时间 | 极端价位。
- 向 02 移交四项：数据基准；级别声明；趋势方向（含依据）；主要摆动序列。

## 2. 第 2 步 数浪（02 数浪）

### 输入确认（缺一项退回 01）

1. 分析级别声明（references/rules.md R22）；2. 趋势方向结论；3. 数据基准；4. 主要摆动序列。

数浪过程中不得更改 01 声明的级别与趋势；只有触发失效后才回退 01（references/rules.md R19、R22）。

### 摆动划分与标注

- 先找推动浪（五浪）再找调整浪（三浪或其变体）；方向与子浪数同时匹配身份（references/rules.md R1、R2）。
- 标注规范：推动 1-2-3-4-5、调整 A-B-C、复合 W-X-Y-Z、三角形 A-B-C-D-E，不得混用（references/rules.md R23）。
- 级别嵌套：当前级别的浪在更小级别应能展开；无法展开的候选段标"待确认"（候选段状态，非清单结论态；按清单三态应判"不适用（前提未证实）"），不得强行命名（references/rules.md R4）。

### 候选数法（强制主备）

- 必须同时给出主方案 + 至少一个替代方案，各自独立标注失效价位（references/rules.md R24）；替代数量通常 1–2 个，极度模糊时可 3 个但须说明原因。
- 候选来源五类分歧：推动 vs 调整；延长 vs 正常五浪；失败 vs 仍在延伸；级别平移；复合结构 vs 单一形态。
- **候选方案四要素**：方案名称、浪段标注、结构说明、关键比率目标（见 `references/fibonacci.md` 第 1 节）。

### Rule Check

逐条检查 references/rules.md 规则，按组核对：

| 检查组 | 规则编号 |
| --- | --- |
| 结构身份 | R1、R2、R3、R4、R21、R25、R30 |
| 推动浪三铁律 | R5、R6、R7 |
| 楔形例外 | R8、R9、R10、R11 |
| 调整浪分类 | R12、R13、R14、R15、R16、R28 |
| 三角形 | R15、R27 |
| 计数规则 | R18 |
| 失败浪 | R17、R29 |

任何一条不满足 → 该方案"规则失效"，不得进入概率排序；主方案失效立即启用替代（references/rules.md R19）。输出格式：规则编号 | 检查结果（通过/不适用/违反）| 备注。

### Guideline Check

对通过 Rule Check 的方案逐条评分：命中 +1 / 未命中或不适用 0 / 明显违反 −1（references/guidelines.md G21）。检查组：G1 交替；G2 等长；G3–G4 通道；G5–G8 比率；G9–G13、G22 延长/失败；G14–G19、G23–G25 形态频率与位置。输出格式：原则编号 | 判定（命中/未命中/违反） | 得分（+1/0/−1） | 说明。

### 失效价位标注与概率排序

- 每个通过 Rule Check 的方案标注独立失效价位（references/rules.md R20；结构失效按第 6 节注）：规则失效价位（R5、R6、R7、R17、R29 等推导，触及即失效）与结构失效价位（预期结构未形成时的降级价位，references/rules.md 第 6 节注）。
- 概率排序按 references/guidelines.md G21 四指标：Guideline 命中数、结构完整度、斐波那契共振、失效价位距离（越远越安全）；排序不产生合法性判断。

### 向 03 验证数浪移交（6 项）

1. 主方案完整标注（浪段 + 结构 + 比率目标）；2. 替代方案完整标注；3. 各方案 Rule Check 结果；4. 各方案 Guideline Check 结果；5. 各方案失效价位；6. 概率排序表。

## 3. 第 3 步 验证数浪（03 验证数浪）

**只验证，不重新数浪**：发现矛盾时标记问题并退回 02，不得现场修改数法；严重问题（级别嵌套不自洽、R5、R6、R7 误判）退回 01 重新确认级别。

### 输入确认（6 项齐全）

主方案完整标注；替代方案完整标注；Rule Check 结果；Guideline Check 结果；失效价位；概率排序表。

### 四步验证

1. **结构自洽**：级别嵌套（references/rules.md R4）、标注规范（references/rules.md R23）、方向身份（references/rules.md R25、R30）、计数一致（references/rules.md R18）；
2. **Rule 复核**：对"通过"抽样复核、对"不适用"检查理由（区分"与方案无关"与"前提未证实"）、对标记"不适用（前提未证实）"的条目检查前提是否确实未证实且跟踪条件明确；发现误判标记"规则误判"退回 02（references/rules.md R19）。复核重点：三铁律极端价位（R5、R6、R7、R20）、调整浪分类（R12、R13、R14、R15、R16、R28）、三角形（R15、R27）、楔形例外（R8、R9、R10、R11）、输出规范（R22、R23、R24）；
3. **Guideline 复核**：评分遗漏、跨方案一致性（如 G1 主方案+1 替代方案是否漏评）、罕见形态降权（references/guidelines.md G14）；比率按极端价位与正确基准（references/rules.md R20；references/fibonacci.md 第 2 节）；
4. **失效价位验证**：独立性（references/rules.md R24）、极端价位（references/rules.md R20）、可执行性、规则对应（R5/R7/R29）、结构失效是否标注。

### 输出完整性检查

R22 级别声明；R23 标注规范；R24 主备方案；概率排序依据（references/guidelines.md G21）；交易计划建议。

### 交接

- 验证通过 → 向 04 移交 6 项：验证后的主/替代方案、概率排序表、失效价位清单（规则 + 结构）、问题摘要（含"建议关注"项）、交易计划建议概要。
- 验证不通过 → 退回 02 修正；严重问题退回 01。

## 4. 第 4 步 生成报告（04 生成报告）

### 输出归档（先建目录，再生成）

- 开始生成报告前，先创建本次分析的专属归档文件夹：`<项目根目录>/分析输出/<标的名称_代码_YYYYMMDD_HHMM>/`（`<项目根目录>` 为运行本次分析的工作区根目录，本仓库示例：`C:\games\Softwares\Codex\波浪skill\分析输出\`）；本地时间 4 位，Windows 文件夹名禁止冒号，例如 `科创50_1B0688_20260809_1522`（不能写 `15:22`）。
- 该文件夹内**只放两个交付文档**（分析报告_*.md 与 网页报告_*.html）；浪型图 PNG 仅存于 `图表/` 子目录作内嵌素材（默认由 2.3 节转 base64 内嵌，仅回退模式用绝对路径）；**不生成**原始行情 CSV、独立的失效追踪、交易计划、变更日志文件（内容分别并入报告第 5/6/8 章）。

只做表述规范化，不改数法、不改排序、不改失效价位。

### 2.1 K 线图 + 浪型标注输出

获取行情数据后、报告定稿前，用 `scripts/ew_chart.py` 绘制"K 线图 + 浪型标注"（脚本优先 matplotlib + mplfinance，mplfinance 不可用时自动回退原生蜡烛图）：

- **每个候选方案画两张图——全景图 + 放大图**（图片数量 = 候选方案数 × 2；歧义极大出现第 3 个备选时可加画，但必须在报告风险提示说明原因——图表数量为工作流输出约定，见第 4 步第 2.1 节）：
  - 全景图：覆盖完整数据范围（数据起点不得擅自截断，图注标注"起点至最新"），只标注大级别结构（1-2-3-4-5 / A-B-C / W-X-Y）与大级别失效价位，禁止标注子浪细节；
  - 放大图：用 `--last N` 截取尾部区间（默认最近 250 根，或按用户指定区间），标注子浪编号（①②③ 或 i-iii）、支撑/阻力、失效价位与当前价格，建议 `--font-scale 1.2–1.4` 保证子浪标注清晰；
- **每张图只画一个方案**，禁止主备混叠（避免混用标注，references/rules.md R23）；
- K 线用开盘/最高/最低/收盘四价绘制（含影线，references/rules.md R20），x 轴时间、y 轴价格；
- 每张图保存为 PNG，文件名含方案名；交付文档中的图片嵌入由 2.3 节自动完成；
- 保存后必须验证文件存在且非空可渲染，否则不得交付。

**每张图必须包含的标注**：

1. 图标题：分析级别（references/rules.md R22）+ 方案名 + 时间范围；
2. 浪段标注：推动 1-2-3-4-5、调整 A-B-C、三角形 A-B-C-D-E、复合 W-X-Y-Z（references/rules.md R23），同一张图不混用；
3. 每段浪的形态类型备注（箭头 + 文字，标注在浪段终点附近）；
4. 关键价位标注：极端价位小十字 + 价格；失效价位红色虚线 + 价格标签 + 对应规则编号（references/rules.md R19、R20）；当前价格水平实线；比率目标浅色区间或水平虚线（references/fibonacci.md）；两图使用同一套颜色（失效红、支撑/阻力蓝、浪号主深副浅）；
5. 注释可读性：带引线、不互相遮挡；右下角或图例注明方案名。

> 输出用高清 PNG（dpi ≥ 150，脚本默认 180）；命名规范：主方案_全景.png、主方案_放大.png、替代方案_全景.png、替代方案_放大.png（references/rules.md R24 要求至少主备两方案；若极端情况仅 1 个合法方案，防御性输出其全景 + 放大 2 张）。

**图表自检清单**（定稿前逐项勾选）：级别已入标题；标注未混用；失效价位带规则编号；PNG 存在且非空；已按 2.3 节内嵌（或回退绝对路径）。

### 2.2 输出顺序与末尾简洁总结

交付按以下顺序组织：

1. **简明分析说明（3–5 段以内）**：标的、周期与声明级别（references/rules.md R22）；主备方案各一句话（R24）；Rule 校验结论（哪条规则决定取舍，如"第 4 子浪与第 1 子浪重叠，违反 R7，故改用楔形假设"）；Guideline 概率排序依据（主备评分与失效距离，references/guidelines.md G21）；
2. **浪型标注图**：按上文 2.1 绘制，放在总结之前；
3. **简洁总结（所有内容最后，≤15 行）**：严格按 assets 报告模板"末尾简洁总结"字段输出（核心判断 / 当前关键形态 / 备选方案 / 概率与仓位 / 关键价位 / 核心方法论启示），每字段 1–3 句话，只给结论、关键价位与仓位，禁止复述分析过程；概率表述用"大概率/倾向于/通常"（references/guidelines.md 前言）。

该顺序是两份交付物的共同骨架：`分析报告.md` 以 8 章节为正文（简明分析置于第 1 章前、浪型图嵌入主/备方案章节、简洁总结置于末尾）；`网页报告.html` 为同内容的快捷查看版（页头 → 简明分析 → 主备方案图标签页 → 简洁总结），不新增内容。

### 2.3 图片内嵌与自包含交付

- 报告与网页归档后，运行 `scripts/embed_report_images.py <归档文件夹>` 自动内嵌：
  - **网页报告.html**：把 `图表/` 下 4 张 PNG（主方案/替代方案 × 全景/放大）转 base64，填入 `{{主方案全景图路径}}` 等 4 个 `<img>` 占位符，不再依赖外部相对路径；
  - **分析报告.md**：把 4 张 PNG 转 base64，写成 `![说明](data:image/png;base64,...)`；若用户查看器不支持 data URI，加 `--md-keep-absolute` 回退为绝对路径引用，保留 `图表/` 目录并在文末注明回退原因。
- 生成后自动校验，任一不通过则以退出码 1 结束、禁止交付缺图文件：
  - html 必须包含 `data:image/png;base64,`，数量等于 `<img class="pano-img">` 数量（标准模板为 4），且无 `{{...图路径}}` 占位符残留；
  - md 必须包含 4 个图片标记（base64 data URI，或回退模式下存在的绝对路径）。
- 校验不通过时，从原始模板重新生成后再次运行脚本；禁止手工粘贴 base64。

### 撰写规范

- 术语「中文（English）」；标注不混用（references/rules.md R23）；提及浪段必须附带级别（references/rules.md R22）。
- 概率表述用"概率较高/倾向于/通常"，禁止"必然/一定/绝对"（references/guidelines.md 前言）。
- 失效价位必须写明"价格触及 X 价位（按极端价位，含影线）时，Y 方案失效，切换至 Z 方案"（references/rules.md R19、R20）。

### 交易计划与概率绑定

仓位按主 − 替代 Guideline 得分差三档：

| 得分差（Guideline 原始得分） | 仓位建议 |
| --- | --- |
| ≥3 分 | 按主方案建仓，替代作为止损触发后退路 |
| 2 分 | 轻仓试探，以主方案为主，保留替代退出路径 |
| ≤1 分 | 观望或轻仓试探，等待结构清晰 |

- 失效价位越远仓位可越重；失效价位很近时即使主方案概率高也应控制仓位（references/guidelines.md G21）。
- 止损位以失效价位为依据，按极端价位设置（references/rules.md R20）。

### 交付物规范（每次分析只交付两个文档）

- 归档位置：`<项目根目录>/分析输出/<标的名称_代码_YYYYMMDD_HHMM>/`（归档规范见本文第 4 步「输出归档」）；
- **分析报告_<标的>_<代码>_<时间>.md**：按 `assets/分析报告_report.md` 模板输出；交易计划（第 6 章）、失效价位（第 5 章）、更新与跟踪（第 8 章）内容完整并入，不再单独成文件；浪型图由 2.3 节转 base64 内嵌（回退模式下用绝对路径引用 `分析输出/<文件夹名>/图表/<PNG>` 并在文末注明），文档自包含；
- **网页报告_<标的>_<代码>_<时间>.html**：复制 `assets/网页报告_web_report.html` **直接填充**生成（所有 `{{字段名}}` 替换为本次分析数据；图区 4 个图片占位符由 2.3 节脚本自动注入 base64，禁止手工填路径），禁止从零重写 HTML 结构；
- 两份文档中主备方案、失效价位、概率排序、简洁总结、关键价位表必须一致。

**不再生成**：独立交易计划.md、失效追踪.md、变更日志.md、日线 CSV（行情数据仅用于分析过程）、独立 PNG（浪型图仅作内嵌素材存于 `图表/` 子目录）。

报告生成后交付用户并归档，失效价位清单移交 05 作为监控输入。

## 5. 第 5 步 更新数浪（05 更新数浪）

### 基准输入（7 项）

已验证主方案；已验证替代方案；失效价位清单；概率排序表；问题摘要；交易计划建议概要；分析级别声明。新增输入：新市场数据（按极端价位读取，references/rules.md R20）。

### 更新三原则

- **失效优先**：首先检查是否触及失效价位，触及必须处理；
- **最小改动**：未触及失效价位时优先微调子浪细分，不推翻整体；
- **级别不变**：除非 H2/H3 等硬性条件触发证明级别崩溃，否则不得擅自升降级别（references/rules.md R4、R22）。

### 失效价位监控（第 2 节）

- 监控对象：主方案失效价位、各替代失效价位、结构失效价位。
- 判定标准：规则失效按极端价位**盘中触及即触发**，无"有效突破"滤网（references/rules.md R20）；结构失效默认"不回抽"= 突破后**连续 2 根 K 线收盘价位于边界外侧**（references/defaults.md D1），单根影线刺破仅记录、不触发；口径优先级：形态文件定义 ＞ 默认口径 ＞ 自定义口径（须在报告披露）。
- 触及分支：主失效替代未失效 → 替代升级并重新执行 03 验证；全部失效 → 硬性重数退回 02；仅结构失效 → 降级"观察中"并行跟踪替代（references/rules.md 第 6 节注）。
- 输出《失效监控记录表》：方案名称 | 失效价位 | 当前价格 | 是否触及 | 处理动作。

### 触发条件判定（第 3 节）

**硬性触发（必须退回 02 重新数浪）**：

- **H1 推动浪三铁律违反**：价格行为违反 R5、R6、R7；
- **H2 级别嵌套崩溃**：当前级别推动浪在更小级别无法展开为任何合法结构（references/rules.md R4）；
- **H3 关键通道被决定性突破**：通道边界被突破（按极端价位）后连续 2 根 K 线收盘价位于通道边界外侧（与结构失效默认口径一致，见本文件第 5 步第 2 节）；仅影线刺破不触发。触发前必须确认通道级别与端点（基线 = 连接第 1 浪终点与第 3 浪终点 + 过第 2/4 浪终点的平行线）；第 3 浪延长时通道需重画；楔形不适用平行通道突破判定；
- **H4 延长浪后的第五浪失败且无法归入其他形态**（references/rules.md R17、R29；详见本步第 6 节）。

**软性触发（建议重估，不强制退回）**：

- **S1 时间/比例严重偏离**：比率未达本身不失效，系统性偏离才触发重估（references/guidelines.md G5–G8）；
- **S2 调整浪细分持续不符**：超过 3 个时间单位持续不符，且切换形态后 Guideline 评分显著提升（references/guidelines.md G21）；
- **S3 罕见复合结构早期迹象**：三锯齿形/三重三浪早期迹象，原计数权重下调（references/guidelines.md G14）。

**不触发条件**：正常子浪内部回撤/反弹；结构失效单根影线刺破未确认；规则失效不存在"不触发"情形（references/rules.md R20）。

输出《触发条件判定表》：条件类型 | 具体表现 | 是否触发 | 处理动作。

### 主备方案管理与升级（第 4 节）

- 任何时刻保持至少一个有效替代（references/rules.md R24）；替代失效后若活跃方案 <2 个，基于当前价格行为生成新替代。
- 升级裁决：计算各替代加权总分 → 总分差 ≥2 分高分者升级；≤1 分比失效距离（更远者升级）；失效距离相近（相对差 < 当前价格 10%，项目默认口径，须披露）比结构完整度；仍无法区分则并列保留、下一周期再裁决。升级后重新执行 03 验证。
- 输出《方案状态管理表》：方案名称 | 原状态 | 新状态 | 变更原因 | 失效价位。

### 调整浪的重新评估与形态切换（第 5 节）

- 触发条件：调整浪细分与最初假设持续不符时启动重评估（软性触发 S2 后的系统核对）。
- 形态切换决策树：
  - 假设锯齿形（Zigzag）：A 浪五浪但 C 浪未按预期完成五浪、且 B 浪回撤超过 A 浪 61.8% → 优先切换平台形（references/guidelines.md G5）；
  - 假设平台形（Flat）：C 浪超出常见比率目标仍无止境，或 B 浪终点明显超过 A 浪起点（扩张/奔走特征）→ 按 references/rules.md R28 切换/细分变体；C 浪走出完整五浪且结构支持 → 检查是否切换锯齿形（references/rules.md R14）；
  - 假设三角形（Triangle）：E 浪突破 A–C 连线或子浪出现五浪结构 → 取消三角形，切换平台形或联合形（references/rules.md R15、R27）；
  - 假设联合形（Combination）：X 浪过深或第二个修正结构无法识别 → 升级为更高级别锯齿形/平台形重估。
- 切换后验证：任何形态切换后必须重新检查 R12、R13、R14、R15、R16、R28 分类条件是否同时满足（references/rules.md）。
- 输出《调整浪形态切换记录》：原假设 | 不符证据 | 新假设 | 验证结果。

### 延长浪与失败第五浪的数浪更新（第 6 节）

- 第三浪延长确认后：第 5 浪通常与第 1 浪等长或呈 0.618 关系；第 5 浪超过第 1 浪 1.618 倍 → 重新评估第 5 浪自身延长（references/guidelines.md G2、G9；references/fibonacci.md 第 1 节）。
- 第五浪延长确认后：A 浪起点以延长浪终点为基准，不得回溯；预期双回撤（references/rules.md R18；references/guidelines.md G11）。
- 九浪序列等效：延长浪内部九浪必须等效为五浪，不得拆分为两个同级推动浪（references/rules.md R18）。
- 延长浪评估清单：内部可数出完整 1-2-3-4-5（references/rules.md R26）；满足 R5、R6、R7；九浪等效单浪（R18）；与相邻非延长浪呈 1.618/2.618 关系（references/guidelines.md G6）；双回撤迹象（G11）；级别嵌套自洽（references/rules.md R4）。
- 失败第五浪识别：第 5 浪未超越第 3 浪终点且内部为完整五浪（references/rules.md R17、R29）；子浪结构不完整不得判定失败（references/guidelines.md G12）。
- 识别后立即重新评估更大级别结构：失败第五浪通常预示更大级别调整展开，或当前级别实为更大调整浪的 C 浪（references/guidelines.md G22）。
- 失败第五浪失效价位：统一设定为第 3 浪终点（按极端价位）——上升趋势向上突破即失效、下降趋势向下跌破即失效（references/rules.md R29、R20）。
- 输出《特殊形态更新记录》：形态类型 | 原定位 | 新定位 | 后续影响。

### 概率重新排序（第 7 节）

任何方案经历失效、升级、形态切换或延长确认后必须重新 Guideline 评分。评分维度（权重 2:1:1:1，04 报告必须披露）：

| 维度 | 权重 | 计分口径 |
| --- | --- | --- |
| Guideline 命中数 | ×2 | 命中 +1、不适用 0、违反 −1，累计 ×2 |
| 结构完整度 | ×1 | 子浪细分清晰且级别嵌套自洽 = 2；基本清晰 = 1；部分待确认 = 0 |
| 斐波那契共振 | ×1 | 关键比率命中 ≥2 个 = 2；1 个 = 1；0 个 = 0 |
| 失效距离 | ×1 | 距当前价 ≥1.618× 基准浪长度 = 2；0.618–1.618× = 1；<0.618× = 0 |

排序规则：加权总分 = 2×Guideline + 结构完整度 + 共振 + 失效距离；按总分降序；**总分相同优先选择失效距离更远的方案**（references/guidelines.md G21）。输出《更新后概率排序表》：方案名称 | Guideline 评分 | 结构完整度 | 共振数 | 失效距离 | 总分 | 排序。

- 交易计划调整：基于新排序按第 4 步「交易计划与概率绑定」三档规则调整仓位与计划（以 Guideline 原始得分差为准，不乘 2；加权总分只用于排序与升级裁决）。

### 变更日志与交接（第 8 节）

- 变更日志字段：改动内容 | 改动原因 | 引用依据。
- 字段映射（与 04 报告章节衔接）：更新后的主方案（含级别声明）→ 报告【1. 分析前提】+【2. 主方案】；更新后的替代方案 →【3. 替代方案】；更新后概率排序表 →【4. 概率排序与理由】；新失效价位清单 →【5. 失效价位清单】；交易计划建议概要 →【6. 交易计划建议】；变更日志（含问题摘要）→【7. 风险提示】+【8. 更新与跟踪】。
- 向 04 移交 6 项：更新后主/替代方案、概率排序表、失效价位清单、交易计划建议概要、**变更日志**（承担问题摘要职能）。
- 更新中遇无法解决的矛盾（级别嵌套崩溃、R5、R6、R7 硬性违反）→ 标记"需退回 02 重新数浪"并附问题摘要。
- 更新输出写回同一标的的归档文件夹 `分析输出/<标的名称_代码_YYYYMMDD_HHMM>/`，变更日志追加到该文件夹；确需从头重开时新建带新时间戳的文件夹并在旧文件夹变更日志中登记去向。

## 6. 交接总览与更新原则

```text
01 分析市场（输出卡：级别+趋势+数据基准+摆动序列）
  ↓ 4 项
02 数浪（候选主备 → Rule Check → Guideline Check → 失效价位 → 概率排序）
  ↓ 6 项
03 验证数浪（只验证不改数；通过移交 / 不通过退回 02，严重回 01）
  ↓ 6 项
04 生成报告（8 章节 + 交易计划与概率绑定）
  ↓ 报告归档 + 失效价位清单
05 更新数浪（失效优先 → 触发判定 → 主备维护 → 调整浪重估 → 延长/失败处理 → 概率重排 → 变更日志）
  ↓ 6 项（含变更日志）→ 回到 04 / 触发硬性条件退回 02
```

底线：**未触发硬性条件不得推倒重数；任何变更必须留痕并给出引用依据**。
